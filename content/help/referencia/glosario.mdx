# Glosário do RKT

Termos usados nas telas, nos relatórios e na documentação da plataforma. Para a definição normativa dos termos legais, consulte a [Política de Privacidade](/privacidade) e os [Termos de Uso](/termos).

## Papéis e perfis

| Termo | Significado |
|---|---|
| **Atleta** | Perfil de quem joga: cria partidas, vê o próprio histórico e relatórios. |
| **Treinador** | Perfil que acompanha atletas e partidas (de clube ou particular). |
| **Gestor** | Perfil que administra o clube: membros, partidas e dados do clube. |
| **Responsável** | Perfil do responsável legal por menores: autorizações, acessos e partidas dos dependentes. |
| **Espectador** | Perfil que acompanha partidas públicas e transmissões ao vivo. |
| **Anotador** | Perfil que registra os pontos das partidas em tempo real. |
| **Área** | Perfil ativo da sessão (ex.: ATLETA, GESTOR). Contas com mais de um perfil trocam em [Escolher Área](/escolher-area). |

## Formatos e pontuação

| Termo | Significado |
|---|---|
| **Game** | Unidade de um set; vencido com 4 pontos e margem de 2. |
| **Set** | Conjunto de games; o placar é 6-x com margem de 2 (ou tiebreak). |
| **Deuce** | Empate em 40-40. |
| **Advantage (Adv.)** | Vantagem após o deuce. |
| **Break Point** | Ponto em que o recebedor pode quebrar o saque. |
| **Game Ball / Set Ball / Match Ball** | Ponto que pode encerrar, respectivamente, o game, o set ou a partida. |
| **Tiebreak** | Game de desempate até 7 pontos (margem de 2). |
| **Match Tiebreak** | Set final disputado como tiebreak até 10 pontos. |
| **No-Ad** | No deuce, o próximo ponto decide o game. |
| **Pro Set** | Set expandido até 8 games com margem de 2. |

## Anotação e timeline

**Siglas de cada ponto na timeline:**

| Sigla | Significado |
|---|---|
| **ENF** | Erro não forçado |
| **EF** | Erro forçado |
| **W** | Winner (ponto vencedor direto) |
| **DF** | Dupla falta |
| **FH / BH** | Forehand / Backhand |
| **VFH / VBH** | Voleio de forehand / backhand |
| **Sm** | Smash |
| **DEV** | Devolução |
| **FQ** | Falta no saque (1º saque na rede ou fora) |
| **Sq** | Saque |
| **Pass** | Passing shot |

| Termo | Significado |
|---|---|
| **Rally** | Sequência de bolas do ponto; a anotação registra vencedor, situação, tipo e golpe. |
| **Undo** | Desfaz o último ponto registrado, restaurando o placar anterior exato. |
| **Correção de placar** | Edição de um ponto já confirmado, com registro de auditoria (o placar anterior fica guardado). |

## Transmissão e acompanhamento

| Termo | Significado |
|---|---|
| **Partida pública** | Partida aberta, listada em Partidas Públicas para qualquer pessoa. |
| **Partida fechada (círculo)** | Partida de acesso restrito aos convidados, com limite de lotação de espectadores. |
| **Link de acompanhamento** | Link gerado pelo compartilhamento da partida para ver o ponto a ponto em tempo real. |
| **Diff de auditoria** | Aviso visual do que mudou quando um placar é corrigido durante a transmissão. |
| **Ritmo da partida** | Indicador baseado no tempo entre os últimos pontos anotados. |
| **Reconexão** | Retomada automática da transmissão quando a conexão cai, sem perder o estado. |

## Contas e vínculos

| Termo | Significado |
|---|---|
| **Convite** | E-mail/link de adesão com token de validade limitada. |
| **Vínculo** | Relação entre treinador e atleta (ou atleta e clube) aceita pelo destinatário. |
| **Regenerar link** | Substitui um link de convite anterior, que deixa de valer. |
| **Solicitação** | Pedido de vínculo ou acesso pendente de aprovação. |

## Privacidade (LGPD e ECA Digital)

| Termo | Significado |
|---|---|
| **Titular** | Pessoa dona dos dados pessoais. |
| **Encarregado (DPO)** | Canal oficial de privacidade: suporte@omni-sistemas.com. |
| **Monotutela** | Um responsável legal ativo por vez para o menor. |
| **Autorizações (DATA, BROADCAST, STATS)** | As três permissões independentes do responsável: dados, transmissão e estatísticas. |
| **Pseudônimo** | Identificador `Atleta #XXXXXX` usado no lugar do nome do menor em transmissões e estatísticas. |
| **Emancipação** | Ao completar 18 anos, o titular assume a gestão da própria conta. |
