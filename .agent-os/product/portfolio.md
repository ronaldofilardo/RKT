# Portfólio de Projetos - C:\apps

Catálogo central de aplicações gerenciadas pelo ecossistema Agent OS:

- **Anthropo**: Aplicação Next.js fullstack com App Router, Prisma ORM e interface moderna.
- **BotLead**: Plataforma de automação e captação de leads via mensageria/IA.
- **HM**: Sistema de gestão e módulos especializados.
- **LWOS**: Lightweight Web Operating System / dashboard de controle.
- **mundoas**: Portal e ecossistema de conteúdo/serviços.
- **OS-LP**: Landing pages de alta conversão orientadas a produto.
- **prot**: Ambiente de prototipagem rápida e validação de MVPs.
- **QWork**: Gerador de relatórios e automação de fluxos de trabalho.
- **qwork-lp**: Landing page oficial da solução QWork.
- **Reporte**: Sistema de exportação e consolidação de métricas e relatórios.
- **RKT**: Ferramentas e otimizações de token/CLI (Rust Token Killer).
